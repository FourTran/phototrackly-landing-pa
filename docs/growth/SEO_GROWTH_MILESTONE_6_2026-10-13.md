## Phase 6.4 — Referral measurement and proof system

- Acquisition rows: **521 Direct sessions / 26 engaged**; 1 unassigned / 0 engaged; **1 `tagassistant.google.com` referral / 1 engaged**.
- **0 independently confirmed external publisher referral sessions** and 0 qualified external registrations. Direct traffic is unverified and predominantly low-engagement; do not treat all 521 as actual buyers. Tag Assistant is a QA/test referrer, not earned distribution.
- GSC finalized Sept 14–Oct 11: **29 impressions, 0 Google organic clicks**. No ranking/CTR signal tied to external distribution exists.
- A GA4 `form_submit` or `generate_lead` event is not a verified persisted qualified registration; verify row/receipt and source separately.

**Working scorecard implemented:** `npm run growth:distribution` generates a read-only markdown status snapshot using:
- `data/growth-distribution-opportunities-2026-10-13.json` — seven real channel candidates with eligibility gates and proof statuses.
- `data/growth-referral-baseline-2026-10-13.json` — source/channel and engagement baseline.
- `scripts/growth-distribution-scorecard.mjs` — generates only `https://phototrackly.com` links with a strict 4-field UTM whitelist, rejects unapproved/no-evidence `published` status, preserves no-outreach/no-payment policies, never logs emails/tokens, and **does not send or post anything**.
- `tests/growth-distribution-scorecard.test.mjs` — insists external proof URL before recording publication, rejects fake on-site proof, records no claimed external sessions, does not count Direct traffic as referrals.

Tracking parameters are for **future** genuine publisher links; they are **not evidence** that the link has been submitted or used. If a publisher strips UTMs or traffic doesn't grant analytics consent, referral attribution can be incomplete; report quality carefully. This work does not change GA4/GTM config or the website's analytics consent rules.
